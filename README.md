# 🎮 Simon Game (JavaScript)

A browser-based implementation of the classic **Simon Memory Game**, built using **HTML, CSS, and Vanilla JavaScript**. This project was developed as part of my JavaScript learning journey to practice fundamental concepts such as **DOM manipulation, event handling, functions, conditional logic, and game state management**.

## 🌐 Live Demo

**🔗 Play the Game:**
https://js-simon-game-lyart.vercel.app/

---

## 📌 Overview

The Simon Game challenges players to remember and repeat an increasingly long sequence of colored buttons. With every successful round, a new color is added to the sequence, making the game progressively more difficult.

This project demonstrates how JavaScript can be used to create interactive web applications by combining HTML, CSS, and dynamic DOM manipulation.

---

## ✨ Features

* 🎮 Interactive Simon Memory Game
* 🎨 Button flash animations for game and user interactions
* 📈 Progressive difficulty with each successful level
* ❌ Game Over detection for incorrect sequences
* 🔄 Restart the game by pressing any key after Game Over
* 🏆 Displays the player's final score after the game ends
* 📱 Responsive user interface
* ⚡ Built entirely using Vanilla JavaScript

## 🎯 How to Play

1. Press any key to start the game.
2. Watch the color sequence displayed by the game.
3. Repeat the sequence by clicking the buttons in the correct order.
4. Each successful level adds one new color to the sequence.
5. If you click the wrong button, the game ends.
6. Your final score is displayed, and you can press any key to start a new game.
